# 💰 Fin-Asistent — Telegram бот финансового ассистента

AI-помощник по личным финансам для студентов (18–25 лет). Бот анализирует ваш бюджет, отвечает на вопросы типа "Могу ли я потратить 3000 рублей?", показывает, хватит ли денег до стипендии, и помогает спланировать траты.

## 🎯 Возможности

- **Умный анализ бюджета** — бот учитывает постоянные расходы, учится из истории, знает о ближайших доходах и платежах
- **Вопросы о покупках** — быстро скажет, можешь ли ты себе позволить покупку, не исчисляя вручную
- **Управление доходами и расходами** — добавляй постоянные (зарплата, стипендия, арендa) и разовые траты (кафе, такси)
- **Накопления и цели** — создавай финансовые цели, копи на них и отслеживай прогресс
- **История операций** — просматривай все свои доходы и расходы за период
- **Промокоды партнёров** — бот предложит скидку Samokat, Ростикс, ДНС и других, когда это уместно
- **Живое общение** — помощник общается по-дружески, без морализирования, понимает твои вопросы

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <repository-url>
cd Fin-Asistent
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Создать файл `.env` в корне проекта

```env
# Telegram
BOT_TOKEN=your_telegram_bot_token

# Groq LLM
GROQ_API_KEY=your_groq_api_key

# PostgreSQL
DB_USER=postgres
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=fin_assist
```

**Где получить ключи:**
- **BOT_TOKEN** — напиши [@BotFather](https://t.me/BotFather) в Telegram, нажми `/newbot`
- **GROQ_API_KEY** — зарегистрируйся на [console.groq.com](https://console.groq.com) и создай API key

### 5. Настроить PostgreSQL

Создай базу данных:

```bash
createdb fin_assist
# или через psql:
# CREATE DATABASE fin_assist;
```

### 6. Применить миграции

```bash
alembic revision --autogenerate -m "Initial schema"
alembic upgrade head
```

**Для Windows** (если asyncpg не работает):
```bash
# Alembic автоматически использует psycopg2 для миграций
# Убедись что psycopg2 установлен: pip install psycopg2-binary
```

### 7. (Опционально) Заполнить промокоды партнёров

```bash
python seed_promos.py
```

### 8. Запустить бота

```bash
python -m bot.main
```

Бот готов! Напиши ему `/start` в Telegram.

## 🔌 API и интеграции

### Groq LLM

Бот использует `gpt-oss-120b` для анализа финансовых вопросов. Модель умеет:
- Понимать финансовый контекст пользователя
- Давать рекомендации на естественном языке
- Использовать tool calling для расчётов (`check_purchase_affordability`)

### PostgreSQL

**Основные таблицы:**
- `users` — пользователи Telegram
- `balance` — текущий баланс
- `income_regular` — зарплата, стипендия, постоянные доходы
- `income_irregular` — разовые доходы
- `expense_regular` — аренда, связь, постоянные расходы
- `expense_irregular` — кафе, такси, разовые траты
- `goals` — финансовые цели и накопления
- `ai_query_log` — история диалогов с ИИ
- `promo_codes` — промокоды партнёров

## 📊 Как это работает

### Типичный поток диалога

```
Пользователь: "Могу ли я потратить 3000 рублей на кроссовки?"
    ↓
1. Бот собирает финансовый контекст из БД:
   - Текущий баланс: 6450 ₽
   - Обязательные расходы до зарплаты: 400 ₽
   - Предыдущие разовые траты: 1500 ₽
   - Следующий доход: через 5 дней
    ↓
2. Передаёт в Groq LLM с финансовым контекстом
    ↓
3. LLM вызывает функцию check_purchase_affordability(3000)
    ↓
4. Возвращает результат:
   - can_afford: true
   - balans_after_purchase: 1950 ₽
    ↓
Ответ: "Кроссовки пройдут 👍. Запас останется, обязательные траты покрыты.
        Но следующие две недели лучше без крупных спонтанных покупок."
```

## 🤖 Возможности ИИ

- **Естественный язык** — понимает русские вопросы и отвечает дружелюбно

## 🎮 Основные операции

### Главное меню

- **💰 Доходы** — добавь постоянные (зарплата) и разовые доходы

## 🔐 Безопасность

- **Валидация** — проверка всех пользовательских вводов

## 🐛 Решение проблем

### PostgreSQL не подключается

```bash
# Проверь, что сервер запущен
# Windows: Services → PostgreSQL
# Linux: sudo systemctl status postgresql
# macOS: brew services start postgresql

# Проверь учётные данные в .env
```

### Groq API возвращает ошибку

- Проверь наличие `GROQ_API_KEY` в `.env`
- Убедись что ключ активен на [console.groq.com](https://console.groq.com)
- Проверь лимит запросов (бесплатный план имеет ограничения)

### Алембик не применяет миграции на Windows

```bash
# Используется psycopg2 для миграций вместо asyncpg
# Установи: pip install psycopg2-binary
# Затем: alembic upgrade head
```
